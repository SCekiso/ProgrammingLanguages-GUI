Project Overview
The Favourite Programming Languages Manager is a C# Windows Forms application that allows users to build, manage and search through a personalized list of programming languages. 
This project demonstrates fundamental UI interactions, list manipulation and basic algorithmic logic like searching and sorting.

Key Features
Dynamic List Management: Easily add new languages to your collection or remove specific entries.
Search Functionality: A dedicated search feature to quickly locate a specific language within the list.
Auto-Sort Capability: Includes an "Auto Sort" toggle to keep the list organized alphabetically in real-time.
Batch Operations: Features a "Clear" function to reset the list and start fresh.

How it Works
Adding: Type a language name in the top text box and click Add.
Searching: Enter a search term in the middle text box and click Search to highlight or find the item.
Removing: Select an item from the list or use the removal field and click Remove.
Sorting: Check the Auto Sort box to keep the list entries ordered automatically.

Tech Stack
Language: C#
Framework: .NET Windows Forms
UI Controls: ListBox (lstLanguages), TextBox, Button, and CheckBox.
IDE: Visual Studio 2022
